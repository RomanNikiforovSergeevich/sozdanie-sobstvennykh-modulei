# Ansible Role: Vector

Эта роль устанавливает и настраивает [Vector](https://vector.dev/) — высокопроизводительный инструмент для сбора, трансформации и маршрутизации логов и метрик — на серверах под управлением Ubuntu/Debian.

## Требования (Requirements)

*   Целевая ОС: Ubuntu 20.04/22.04 или Debian 11/12.
*   Наличие коллекции `community.general` (используется модуль `deb822_repository` для добавления репозитория):

    ansible-galaxy collection install community.general

Что делает роль

    Устанавливает необходимые пакеты (apt-transport-https, curl, python3-debian и др.).

    Добавляет официальный репозиторий Datadog для Vector.

    Устанавливает пакет vector.

    Создает директорию для данных с правильными правами доступа.

    Генерирует базовый конфигурационный файл /etc/vector/vector.yaml из шаблона (настроен на сбор демонстрационных логов и вывод в консоль).

    Запускает службу vector и добавляет её в автозагрузку. Перезапускает службу при изменении конфигурации.

Включение роли в плейбук:

```yaml

- hosts: vector
  become: true
  roles:
    - vector
